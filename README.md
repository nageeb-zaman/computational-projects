# Computational projects

Self-contained computational projects in physics and astronomy: data analysis, simulations
and visualizations. Each folder has its own code, data, results and README, and can be run
on its own.

My research code (supernova modelling and radiative transfer) lives in separate repositories;
see [nageeb-zaman.github.io](https://nageeb-zaman.github.io).

## Projects

| Project | What it does | Tools |
|---|---|---|
| [**NGC 7089 (M2) colour–magnitude diagram**](m2-globular-cluster-cmd/) | Measures the distance (11.7 kpc) and metallicity ([Fe/H] = −1.77) of a globular cluster from V and R images I took with a 20-inch telescope: PSF photometry, Gaia calibration, horizontal-branch distance and isochrone fitting. | Python, photutils, astropy |

More projects will be added here.
